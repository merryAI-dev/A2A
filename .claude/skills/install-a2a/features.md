# A2A 기능 지도 — 무엇이 있고, 어떻게 이어지고, 어떻게 써 보나

설치를 마친 에이전트가 **기능마다 직접 써 보고** 사람에게 결과를 보고하는 데 쓴다.
사람이 처음 둘러볼 때 안내서로 써도 된다. 예시의 숫자(운임 등)는 2026-11-11에 본 값이라 날마다 다르다 — 모양이 맞는지를 본다.

## 한눈에 — 네 층

```
 사람이 보는 화면   홈 · 메리 · 접점 찾기 · 해상 운임 · 학습 · 업무 지도 · 옆 패널(에이전트·팀 채팅)
        │  (맨 위 메뉴로 오가고, 분할 뷰로 둘을 나란히)
 일하는 쪽          옆 패널 에이전트(브라우저 도구 + 엔진 도구) · 메리(투자 검토 보조)
        │  (모든 화면과 에이전트가 같은 엔진 경로를 쓴다 — 화면용·에이전트용이 따로 없다)
 엔진 :8423         접점 찾기 · 해상 운임 · 기기 조회(osquery) · 팀 채팅 · 모델 프록시
        │
 바깥·기록          공개 웹페이지 · 한국해양진흥공사 KCCI 운임 지수 · 이 맥(osquery) · Anthropic 모델
                    └ 모든 작업은 업무 지도(온톨로지)에 "누가 무엇을 근거로 했나"로 남는다
```

틀(세로 탭, 탭 줄 홈 단추, 틀 색, `a2a://` 주소, 옆 패널 자동 열기)은 C++ 패치(`chromium/patches/`)이고, 화면과 에이전트는 내장 확장(`browser-ext/`)이다.

## 기능별 — 어디서, 무엇을, 써 보는 법

각 항목의 "써 보기"를 그대로 해 보고 "되면" 칸과 같으면 됨이다.

### 1. 홈(새 탭)
- **무엇:** 검색·주소 칸, 에이전트에게 일 맡기기, 맨 위 앱 메뉴, 배경화면.
- **써 보기:** 새 탭을 연다 → 맨 위 메뉴에 홈·메리·접점 찾기·해상 운임·학습·업무 지도가 있다 → 검색 칸에 `메리`를 치고 엔터.
- **되면:** 메리 화면이 열린다(우리 화면 이름은 주소처럼 열린다. `a2a://메리`도 같다).

### 2. 옆 패널 — 에이전트
- **무엇:** 지금 탭을 읽고 누르고 쓰는 에이전트. 브라우저 도구(`read_page`·`click`·`type`·`navigate` 등)와 엔진 도구(`find_contacts`·`ocean_freight_rate`·`draft_freight_reply`·`device_query`·`find_app`), 글쓰기(`write_text`), 팀 채널 게시(`post_to_channel`, 올리기 전 승인).
- **써 보기:** 아무 기사 탭을 열고 옆 패널 AI 대화에 "이 페이지 세 줄로 요약해줘".
- **되면:** 요약이 나오고, 업무 지도에 그 작업과 읽은 페이지가 남는다.
- **연결:** 누르기·입력·게시처럼 바깥에 영향이 있는 동작은 승인 창을 띄운다.

### 3. 옆 패널 — 팀 채팅
- **무엇:** 워크스페이스 TEST의 채널(#general 등)과 대화. `@에이전트`로 AI를 부른다.
- **써 보기:** 옆 패널 맨 위 대화 제목을 눌러 대화 목록 → #general.
- **되면:** setup이 넣은 예시 메시지(alice·bob의 대화)가 보인다.
- **기대는 안 됨:** 이 맥의 Postgres·Redis만 쓴다 — 다른 맥 사람과는 이어지지 않는다.

### 4. 메리 — 투자 검토 딜룸
- **무엇:** 지시를 붙여 넣으면 검토를 열고, 공개 웹에서 사실을 찾고(출처 링크), 받을 자료를 정리하고, 판단이 필요한 것을 묻고(답은 "결정"으로 기록), 목차대로 투심보고서를 **가운데 문서에** 쓴다. 대화창은 입력과 진행만 받는다.
- **써 보기:**
  1. 메리 → 왼쪽 위 "지시 붙여넣기" 칸에 회사 소개 글 한 단락을 붙여 넣고 "메리에게 검토 맡기기".
  2. 메리가 웹에서 사실을 찾고, 받을 자료 목록과 질문 2~3개를 낸다 → 선택지를 고른다.
  3. "지금까지 정한 것으로 투심보고서 초안을 가운데 문서에 쓸까요?" → 목차대로 쓰기(섹션 하나에 2~3분, 전체는 30분 안팎 — 점검에는 "시장 분석 써줘"처럼 섹션 하나만).
- **되면:** 가운데 문서에 섹션이 부분씩 차오르고, 대화에는 진행 한 줄과 질문만 남는다. 근거 탭에 출처가 달린 사실이, 논의·결정 탭에 고른 답이 있다.
- **연결:** 메리의 질문·결정·근거는 업무 지도에 남는다. "웹에서 찾아봐"라고 하면 옆 패널 에이전트에게 맡긴다.

### 5. 메리 → 운송비 (해상 운임과 이어짐)
- **써 보기:** 메리 대화에 "이거 이탈리아로 수출하려면 운임이 얼마지?" → "40피트 컨테이너를 얼마나 보낼까요?"에 `월 2대`.
- **되면:**
  - 답에 "이탈리아 → 지중해 항로 $4,177 / 40피트 한 대 (기준일 …)"와 "1년 운송비(한 달 2대 → 1년 24대, 40피트): 지금 시세면 $100,248(4,177 × 24대), 지난 52주 평균이면 …, 범위 …"가 나온다.
  - 메리 옆 칸(분할 뷰)에 해상 운임 화면이 같은 조건으로 채워져 열린다.
  - 근거 탭에 운임이 출처(kobc.or.kr)·기준일과 함께, 결정에 "운송비 계산에 쓸 연간 물량(40피트) → 월 2대"가 들어간다.
- **흐름:** 메리 → 엔진 `/v1/freight/ocean/ask`(문장에서 도착지·물량을 읽음) → KCCI 공개 지수 → 메리 답 + 근거 + 결정 → 옆 칸 `freight.html?to=…&n=…&per=…`.
- **원칙:** 숫자는 엔진이 계산하고 메리는 옮기기만 한다. 지수이지 견적이 아니다. 20피트는 40피트 값을 나눠 추정하지 않는다.

### 6. 해상 운임 화면
- **무엇:** 부산발 13개 항로의 운임 지수(매주 월요일), 기간별 추이 그래프, 도착 항구 카드(스카이스캐너식 — 운항 일수·배편 칸은 출처 연결 전이라 비어 있다), 1년 운송비 카드.
- **써 보기:** 맨 위 메뉴 해상 운임 → 도착에 `이탈리아` → 운임 보기 → 1년 운송비 카드의 대수를 바꿔 본다.
- **되면:** 1년 운송비 큰 숫자와 지금·평균·최저·최고 막대가 계산식과 함께 나오고, 대수를 바꾸면 다시 계산된다. `미국`이면 북미 서안·동안 두 항로로 갈린다.
- **에이전트에서:** 옆 패널에 "미국으로 월 2대 보내면 1년 운임?" → `ocean_freight_rate`가 같은 계산으로 답하고 이 화면을 옆 칸에 연다.
- **에이전트에서(답장):** 운임 문의 메일을 보여 주고 "답장 써줘" → `draft_freight_reply`가 엔진 시세로 사실표를 만들어 초안을 쓴다(보내지 않음).

### 7. 접점 찾기
- **무엇:** 회사 도메인의 공개 페이지(최대 12장)에서 메일 주소를 출처 인용과 함께 찾고, 메일 서버를 확인하고, 회사 공식 채널(SNS·블로그)을 찾는다. 찾는 대로 화면에 올라온다.
- **써 보기:** 접점 찾기 → `mysc.co.kr` → 메일 찾기.
- **되면:** 1~2초 안에 첫 주소(`info@mysc.co.kr`)가 출처 인용과 함께 올라오고, 10초 안팎에 끝난다. 아래 "공식 채널"에 홈페이지가 링크한 계정(네이버 블로그·페이스북·인스타그램·유튜브·카카오톡 채널)이 "홈페이지에 링크됨"으로, 이름만 같은 계정은 접힌 칸에 따로 나온다.
- **에이전트에서:** "mysc.co.kr 연락처 찾아줘" → `find_contacts`가 같은 엔진 경로(`/v1/contacts/discover/stream`)를 쓴다.
- **원칙:** 출처 없는 주소는 없다. 이름+패턴으로 추측한 주소는 "추측"으로 따로 보인다. 개인 아이디 추적은 하지 않는다.

### 8. 기기 조회 (osquery)
- **무엇:** 이 맥의 상태를 읽기 전용으로 — 실행 중인 프로그램, 열린 포트, 브라우저 확장, 디스크 암호화·방화벽, 설치된 앱.
- **써 보기:** 옆 패널에 "이 컴퓨터에 지금 무슨 프로그램이 돌고 있어?" → 승인 창에서 승인. 이어서 "Slack 깔려 있어?"
- **되면:** `device_query`가 허용된 테이블만 읽어 답하고, `find_app`이 앱 폴더에서 찾아 답한다. 승인을 거절하면 읽지 않는다.
- **기대는 안 됨:** 앱 목록 전체(`apps` 테이블)는 느려서(60초 넘음) 쓰지 않고 `find_app`이 대신한다. 맥 전용이다.
- **연결:** 엔진 `/v1/device/*`는 같은 컴퓨터에서 온 요청만 받는다. 실행 파일은 `data/osquery/`(setup이 받음).

### 9. 학습
- **무엇:** 공부할 링크를 주면 코스를 만들고, 설명·질문·연습을 함께 진행한다.
- **써 보기:** 학습 → "공부할 링크" 칸에 `https://browser.engineering/`를 넣고 코스를 만든다.
- **되면:** 코스 목차가 생기고 첫 단원이 열리며, 답을 쓰면 튜터가 이어 간다.

### 10. 업무 지도 · 온톨로지
- **무엇:** 모든 작업(에이전트 작업, 메리의 질문·결정·근거, 읽은 페이지, 엔진 도구 결과, 승인)이 "누가 무엇을 근거로 했나"의 그래프로 쌓이는 곳.
- **써 보기:** 위 점검을 몇 개 한 뒤 맨 위 메뉴 업무 지도.
- **되면:** 방금 한 작업들이 목록·그래프에 보이고, 항목을 누르면 근거(읽은 페이지, 도구 결과)로 이어진다.
- **기대는 안 됨:** 이 맥의 브라우저 프로필에만 쌓인다. 다른 맥과 공유되지 않는다.

### 11. 화면 공통 — 글 선택 · 검색 · 분할 뷰
- **써 보기:** 아무 우리 화면에서 글을 끌어 고른다 → 노란 하이라이트와 "복사 · 검색 · 옆에서 검색" 메뉴 → 검색. 그다음 뒤로 가기. 맨 위 메뉴 오른쪽 "분할 뷰" 누르기 → 다시 누르기.
- **되면:** 검색은 같은 탭에서 열리고 뒤로 가기로 돌아온다. "옆에서 검색"은 옆 칸에 열린다. 분할 뷰는 이 화면 옆에 탭을 붙였다가 다시 누르면 푼다.

## 이어지는 길 — 요약

| 시작 | 거쳐 가는 곳 | 끝 |
|---|---|---|
| 메리 운송비 질문 | 엔진 `/v1/freight/ocean/ask` → KCCI | 메리 답 · 근거 · 결정 · 옆 칸 해상 운임 화면 · 업무 지도 |
| 해상 운임 화면 | 엔진 `/v1/freight/ocean/compare` · `/project` · `/board` | 항구 카드 · 1년 운송비 · 추이 |
| 에이전트 `ocean_freight_rate` | 같은 엔진 경로 | 답 + (show) 옆 칸 화면 · 업무 지도 |
| 접점 찾기 화면 / 에이전트 `find_contacts` | 엔진 `/v1/contacts/discover/stream` → 공개 웹 | 메일·출처·공식 채널 · 업무 지도 |
| 에이전트 `device_query`·`find_app` | 승인 → 엔진 `/v1/device/*` → osquery | 답 · 업무 지도 |
| 에이전트·메리의 AI | 엔진 모델 프록시(`A2A_DEV_LLM_PROXY=1`) → Anthropic | 답 (키는 엔진 `.env`에만) |
| 메리 "웹에서 찾아봐" | 옆 패널 에이전트에게 맡김 | 읽은 페이지가 메리 근거로 |
| 모든 작업 | 기록(`browser/events.js`) | 업무 지도 |

## 안 되면 먼저 볼 곳

| 증상 | 먼저 볼 것 |
|---|---|
| AI 답이 안 나오고 "키가 없어요" | `.env`에 `ANTHROPIC_API_KEY`가 채워졌는지(값은 보지 말고 있는지만), `A2A_DEV_LLM_PROXY=1`, 엔진을 키 넣은 뒤 다시 띄웠는지 |
| 접점·운임·기기 화면이 "엔진 응답 404" | 엔진을 최신 코드로 다시 띄웠는지(`pkill -f "uvicorn app.main:app"; ./run-mac.sh --backend &`) |
| 403 | 브라우저 계정 이름이 `.env`의 `SAAS_ALLOWED_USERS`에 있는지 |
| 운임이 안 나옴 | 인터넷, kobc.or.kr 접속. 공표는 매주 월요일 — 기준일이 2주 넘게 오래되면 화면이 경고한다 |
| 기기 조회 "osquery가 없습니다" | `./scripts/fetch_osquery.sh` |
| 팀 채팅이 비어 있음 | `brew services list`에서 postgresql@17·redis가 started인지, setup의 시드가 돌았는지 |
| 브라우저가 안 뜸(`libchrome_dll.dylib`) | 열린 채로 빌드했는지 — 닫고 다시 빌드 |
